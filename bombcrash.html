Bomb Crash

凍結爆弾でカウントダウン式の敵を迎撃し、スクラップを集めながらWaveの攻略に挑む2Dアクションゲームです。

ゲーム概要 制作体制・技術の見どころ ゲーム進行 設定画面・実装範囲 Wave生成の実装 ソースコード・関連資料

ゲーム概要

Bomb Crashは、凍結爆弾の着弾位置を調整しながら、爆発までのカウントダウンがある敵を迎撃してWaveを攻略する2Dアクションゲームです。

  • 敵はHPと爆発までのカウントダウンを持ち、時間内に倒せないと爆発してゲームオーバーになります。
  • 爆弾の所持数には上限があり、時間経過で補充されます。
  • 敵を倒すとスクラップを獲得します。到達Waveなどに応じた知見ポイント（IP）はリザルトに反映されます。
  • 敵の出現が終わり、フィールド上の敵をすべて倒すと次のWaveへ進みます。Wave数に応じて敵が強くなり、一定間隔でスタンピードやボスが登場します。
  • オトモスキルはZ / X / Cで発動でき、自動発動に設定することもできます。必殺技は使用可能なときにVキーで発動します。

操作

  • 左右移動: ← / →、爆弾の着弾位置調整: ↑ / ↓、爆弾を投げる: Space
  • 装備スキル: Z / X / C、必殺技（使用可能時）: V
  • ホーム画面などのUI操作: マウスクリック、ゲームオーバー演出後にホームへ戻る: Space

ゲーム進行

出撃して敵を迎撃し、Waveを攻略します。プレイ終了時はリザルトを確認し、次の出撃に備えて装備を整えます。

プレイの基本ループと終了条件

  1. 出撃する

    ホーム画面から戦闘を開始します。

  2. 敵を迎撃する

    凍結爆弾の着弾位置を調整し、出現する敵を攻撃します。

  3. Waveを攻略する

    敵の出現が終わり、フィールド上の敵をすべて倒すと次のWaveへ進みます。

  4. プレイを終える

    敵のカウントダウンが尽きて爆発するとゲームオーバーです。リザルトで到達Waveや獲得資源を確認します。

オトモスキルの装備と発動

  1. オトモにスキルを装備する

    装備スロットに使用するスキルを設定します。

  2. 発動方法を選ぶ

    スキルごとに手動発動または自動発動を設定します。

  3. 戦闘中に発動する

    手動の場合はZ / X / Cで発動します。自動の場合は設定とクールタイムに応じて発動します。

装備を整える

  1. スクラップを集める

    敵を倒して装備の購入・強化に使う資源を獲得します。

  2. 装備を購入・強化する

    集めたスクラップを使って装備を整えます。

  3. 次の出撃に備える

    整えた装備で、さらに先のWaveへ挑戦します。

オトモを編成する

  1. オトモを解放する

    到達Waveの条件を満たしてオトモを解放します。

  2. オトモにスキルを設定する

    解放したオトモに、戦闘で使用するスキルを装備します。

  3. 戦闘で支援を受ける

    装備したスキルが、設定した発動方法に応じて戦闘中に発動します。

実装の詳細：Wave生成とスキル発動

ここでは、Wave生成・敵出現と、オトモスキルの装備・発動を担当するクラスの処理を紹介します。

Wave生成と進行を分担する

EndlessWaveRuleは通常Wave・スタンピードの時間や出現間隔、敵パターンの開始Wave・ピークWave・最大比重を保持します。WaveGeneratorはWave番号とルールから出現時間・間隔・スタンピード状態を計算し、敵パターンの比重を線形補間してIntervalWaveDataを生成します。開始Wave前の敵と比重が0の敵は候補から除かれます。

WaveManagerはWaveを開始し、生成データを使ってタイマーやUI、ボス・スタンピードを含む進行を管理します。通常WaveではEnemySpawnControllerがデータの出現間隔で敵を生成し、候補の比重による敵選択、出現位置の決定、敵のHP設定を行います。Wave時間の経過後はフィールド上の敵がいなくなるまで待ち、次のWaveへ進みます。

オトモスキルの装備と発動

OtomoSkillManagerは出撃時に装備スロットの内容を読み取り、装備中のスキル一覧を更新します。OtomoSkillRunnerはその一覧を戦闘画面のスロットに反映し、Z / X / Cの入力または自動発動条件に応じてスキルを実行します。実行後のクールタイムも同クラスが更新します。

SkillSOはスキルのカテゴリ・アイコン・名前・レアリティ・自動発動設定・クールタイム・ストック・覚醒回数などを持つ抽象ScriptableObjectです。効果説明、覚醒に応じたクールタイム、実行処理は派生クラスで定義します。
