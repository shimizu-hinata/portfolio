Bomb Crash

BombCrash は Unity で制作した、2D アクションゲームです。
プレイヤーは強力な凍結爆弾を武器に、カウントダウン式の敵ボムが爆発する前に次々と撃破していきます。
敵を倒してスクラップを集め、装備を購入・強化しながら、どこまでウェーブを生き延びられるか挑戦します。知見ポイント（IP）は到達状況などに応じてリザルトで獲得します。

ゲーム概要

「BombCrash」は、次々と湧いてくるカウントダウン爆弾（敵）を、強力な凍結爆弾で破壊する爽快アクションゲームです。
プレイヤーはキャラクターを操作し、敵を倒してスクラップを入手します。
スクラップは装備の購入・強化に使用します。知見ポイント（IP）はウェーブ到達状況などに応じてリザルトで獲得します。
このゲームでは、Wave(波)の概念を採用しており、Wave数が上がるにつれ敵が強くなっていくようになっています。

  • 敵はHPと爆発までのカウントダウンを持ち、時間切れになる前に撃破する必要があります。
  • プレイヤーは爆弾の着弾位置を調整して投げ、敵を倒すとスクラップを獲得します。爆弾は所持数に上限があり、時間経過で補充されます。
  • スクラップは装備の購入・強化に使用します。知見ポイント（IP）はウェーブ到達状況などに応じてリザルトで獲得します。
  • オトモに装備したスキルはZ / X / Cで使用でき、スキルの設定によっては自動発動します。必殺技は使用可能な状態でVキーから発動します。
  • ウェーブの敵出現が終了し、フィールド上の敵もいなくなると次のウェーブへ進みます。一定間隔のスタンピードやボス出現も設定されています。
  • 敵のカウントダウンが尽きると爆発してゲームオーバーとなり、リザルトで到達ウェーブや獲得資源を確認できます。

操作

  • 左右移動: ← / →、爆弾の着弾位置調整: ↑ / ↓、爆弾を投げる: Space
  • 装備スキル: Z / X / C、必殺技（使用可能時）: V
  • ホーム画面などのUI操作: マウスクリック、ゲームオーバー演出後にホームへ戻る: Space

ゲーム進行・処理フロー

出撃からウェーブ戦闘、リザルトまでのゲーム進行と、ウェーブ設定から敵を出現させる処理の流れです。

プレイの基本ループと終了条件

  1. 出撃ホームからゲームを開始し、ローディングを経て戦闘へ
  2. 敵が出現ウェーブ設定に従って敵がフィールドに登場
  3. 爆弾で迎撃着弾位置を調整して凍結爆弾を投げ、敵を撃破
  4. 次のWave / ゲームオーバー出現終了かつ敵がいなければ次のWaveへ。敵のカウントダウンが尽きた場合はゲームオーバーとなり、リザルトへ

ウェーブ・リザルト処理

  1. ルールから生成EndlessWaveRuleと敵データから時間・出現間隔・候補を構成
  2. 敵を出現・進行WaveManagerが進行とUIを管理し、EnemySpawnControllerが敵を配置
  3. 結果を反映討伐数・スクラップを更新し、到達ウェーブと獲得資源を表示

オトモスキルの装備・発動

  1. 装備を反映出撃時にOtomoSkillManagerが装備スロットのスキルを読み込む
  2. 発動方式を判定OtomoSkillRunnerがZ / X / C入力を確認。自動設定スキルは敵がいる場合に発動を試みる
  3. 発動・再使用待ちSkillSO.Execute()を実行し、設定されたクールタイム中は再発動しない

装備処理フロー

  1. スクラップを獲得敵を撃破してゲーム内資源を入手
  2. 装備を購入・強化スクラップを使って装備を整え、プレイヤー能力を補助
  3. 次の出撃に備える装備内容を確認して、より先のウェーブに挑戦

オトモ処理フロー

  1. オトモを解放一定の到達ウェーブを条件に解放される
  2. スキルを装備オトモにスキルを設定し、手動または設定に応じて自動で使用
  3. 戦闘を支援クールタイムや使用可能状態に従ってスキルを発動

実装のポイント：ウェーブ生成とスキル発動

Bomb Crashでは、敵の登場タイミングと種類をWaveごとに変化させ、装備スキルを入力または条件に応じて発動します。チーム開発で、本人は企画・プログラミングを担当しました。

Waveごとの出現条件を組み立てる

Waveごとの出現条件を設定するEndlessWaveRuleをもとに、WaveGeneratorが回ごとの出現設定を作成。EnemySpawnControllerが敵の比重から出現対象を選び、WaveManagerがボスやスタンピードを含む進行を扱います。

Waveルール · Wave生成 · 敵の出現

スキルの発動方法をそろえる

手動・自動の発動とクールタイムを管理するOtomoSkillRunnerが、装備スロットとZ / X / C入力を扱います。スキル共通の情報と実行口はSkillSOに定義しています。Wave設定とスキル設定の画面は上のスクリーンショットで紹介しています。

スキル定義 · スキル発動処理

今後の改善候補: 敵の出現候補が空の場合を設定時に検出すること、自動スキルの待機処理が重複して起動しないよう状態を管理すること。

ストーリー

BombCrash - 物語のあらすじ

プロローグ

かつて、私の母は父が作った爆弾の誤作動によって命を落とした。

その日以来、父は生きる気力を失ったかのように、自身の研究にさらに深くのめり込んでいった。

まだ幼かった私は、父が作ってくれたウサギ型のロボット人形を抱きしめ、寂しそうに父の研究室を覗き込むことしかできなかった。 そして、静かにその扉を閉じる。

数年後、日常の断絶

私は高校生になった。

学校からの帰り道、いつも通り父の研究室を覗くと、そこには研究に没頭する父の姿があった。私は静かに通り過ぎる。 学生カバンに着けた、昔のロボット人形とお揃いのキーホルダーが、扉の隙間から父の姿をのぞかせていた。

自室に戻ると、そこは私の研究室でもあった。 爆弾の設計に必要な道具が散らばるデスク。 壁には、精密に描かれた凍結爆弾の設計図が貼られている。 デスクの傍らには、幼い頃に抱いていたウサギの人形と、母の顔がかすれてしまった家族写真が置かれていた。

私は学生カバンを置き、再び爆弾の設計に取り掛かる。

回想 - 父との亀裂

数年前、私は初めて自力で開発した爆弾の設計図を父に見せた。

「見て見て！これ私が作ったんだ！」

喜んでもらえると、そう信じていた。 しかし、父からの返答は淡々としたものだった。

「あぁ。すごいじゃないか…。」

期待していた反応は得られず、私は握りしめてくしゃくしゃになった設計図を父に投げつけ、研究室を飛び出した。 自室のベッドにうずくまり、掛け布団を深く覆いかぶせて泣いた。

一方、父は床に落ちた設計図を拾い上げる。

「凍結爆弾か…、よくできている…。」

その呟きは、誰に聞かれることもなく研究室に消えた。

事件の勃発

数週間後、学校から帰宅すると、いつもいるはずの父の姿が研究室から消えていた。

急いで扉を開けて中へ入るが、誰もいない。ただ、父が研究していた爆弾の資料が床に散乱していた。 その設計資料に描かれていたのは、見たこともない爆弾だった。

その時、外から大きな爆発音が響き渡る。

窓の外を見ると、先ほどの資料とそっくりな爆弾が次々と爆発していた。 そして、私のすぐそばに、どこからともなくカウントダウンを始める爆弾が出現する。

このままではやられる――！

私は一か八か、学生カバンから試作品の凍結爆弾を取り出し、敵の爆弾に投げつけた。 爆弾は見る見るうちに凍りつき、完全に凍結されると粉々に砕け散った。

そう、私が開発したこの凍結爆弾だけが、敵を破壊できる唯一の手段だったのだ。

安堵もつかの間、新たな敵性爆弾が次々と現れる。 急いで家に戻ろうとしたが、自宅はすでに跡形もなく爆破されていた。

しかし、地下の研究室へ続くハッチだけは、奇跡的に無事だった。 爆弾研究のために、地下室はほとんどの爆発を無効化できるように設計されている。私の部屋も、研究を始めてから地下に移していた。

地下の自室へ駆け込み、デスクの上に置かれた設計図と完成品の爆弾を見つめる。 私は慣れた手つきで作業着に着替えると、それらを手に地上へと向かった。

父の行方を追い、謎の爆弾を破壊するため、私の戦いが今、始まる。
