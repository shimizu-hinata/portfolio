Bomb Crash

凍結爆弾でカウントダウン式の敵を迎撃し、スクラップを集めながらWaveの攻略に挑む2Dアクションゲームです。

ゲーム概要 制作体制・技術の見どころ ゲーム進行 設定画面・実装範囲 Wave生成・オトモスキルの実装 ソースコード・関連資料

ゲーム概要

Bomb Crashは、凍結爆弾の着弾位置を調整しながら、爆発までのカウントダウンがある敵を迎撃してWaveを攻略する2Dアクションゲームです。

  • 敵はHPと爆発までのカウントダウンを持ち、時間内に倒せないと爆発してゲームオーバーになります。
  • 爆弾の所持数には上限があり、時間経過で補充されます。
  • 敵を倒すとスクラップを獲得します。到達Waveなどに応じた知見ポイント（IP）はリザルトに反映されます。
  • 敵の出現が終わり、フィールド上の敵をすべて倒すと次のWaveへ進みます。Wave数に応じて敵が強くなり、一定間隔でスタンピードやボスが登場します。
  • オトモスキルはZ / X / Cで発動でき、自動発動に設定することもできます。必殺技は使用可能なときにVキーで発動します。

操作

  • 左右移動: ← / →、爆弾の着弾位置調整: ↑ / ↓、爆弾を投げる: Space
  • 装備スキル: Z / X / C、必殺技（使用可能時）: V
  • ホーム画面などのUI操作: マウスクリック、ゲームオーバー演出後にホームへ戻る: Space

ゲーム進行

出撃して敵を迎撃し、Waveを攻略します。プレイ終了時はリザルトを確認し、次の出撃に備えて装備を整えます。

プレイの基本ループと終了条件

  1. 出撃する

    ホーム画面から戦闘を開始します。

  2. 敵を迎撃する

    凍結爆弾の着弾位置を調整し、出現する敵を攻撃します。

  3. Waveを攻略する

    敵の出現が終わり、フィールド上の敵をすべて倒すと次のWaveへ進みます。

  4. プレイを終える

    敵のカウントダウンが尽きて爆発するとゲームオーバーです。リザルトで到達Waveや獲得資源を確認します。

オトモスキルの装備と発動

  1. オトモにスキルを装備する

    装備スロットに使用するスキルを設定します。

  2. 発動方法を選ぶ

    スキルごとに手動発動または自動発動を設定します。

  3. 戦闘中に発動する

    手動の場合はZ / X / Cで発動します。自動の場合は設定とクールタイムに応じて発動します。

装備を整える

  1. スクラップを集める

    敵を倒して装備の購入・強化に使う資源を獲得します。

  2. 装備を購入・強化する

    集めたスクラップを使って装備を整えます。

  3. 次の出撃に備える

    整えた装備で、さらに先のWaveへ挑戦します。

オトモを編成する

  1. オトモを解放する

    到達Waveの条件を満たしてオトモを解放します。

  2. オトモにスキルを設定する

    解放したオトモに、戦闘で使用するスキルを装備します。

  3. 戦闘で支援を受ける

    装備したスキルが、設定した発動方法に応じて戦闘中に発動します。

実装の見どころ：Wave生成とオトモスキル

Wave設定から敵の出現まで、またスキルの装備から発動・効果適用までを、データとクラスのつながりに沿って紹介します。

Wave設定から敵の出現まで

1. 実装した機能

Waveごとの出現時間・間隔・敵候補をルールから作り、時間内に敵を出現させます。敵の数を先に決めるのではなく、Wave時間と出現間隔に沿って生成します。

2. クラス構成

  • EndlessWaveRuleは通常Wave・スタンピードの設定を持つScriptableObjectアセットです。EnemyScalingPatternには敵ごとの出現開始Wave、ピークWave、最大比重を設定します。
  • WaveGenerator.GenerateWave()は設定とWave番号から実行用データを生成します。IntervalWaveDataもScriptableObjectで、メソッド内で実行時インスタンスが作られ、1回分のWave条件とEnemySO・重みの候補配列を持ちます。
  • WaveManagerは生成データを受け取り、Wave番号・タイマー・UI・終了判定を管理します。通常WaveではEnemySpawnControllerにデータを渡し、敵の選択・配置・HP設定を任せます。

3. 処理の流れ

  1. WaveManagerがWaveGenerator.GenerateWave()にWave番号とEndlessWaveRuleを渡します。

  2. WaveGeneratorは各敵の開始Waveより前なら候補から除き、それ以外はMathf.InverseLerpで開始からピークまでの進み具合を求め、Mathf.Lerpで0から最大比重までを計算します。結果を含むIntervalWaveDataを返します。

  3. WaveManagerはそのデータを保持し、通常WaveではEnemySpawnController.StartSpawnEnemy()へ渡します。敵の出現時間が終わり、フィールド上の敵がいなくなると次のWaveに進みます。

4. 設計上の工夫と利点

設定値を持つEndlessWaveRuleと、1回分の生成結果を持つIntervalWaveDataを分けています。敵ごとの登場時期や比重はルール側で調整でき、生成器はその設定から実行用データを組み立てます。また、WaveManagerが進行を、EnemySpawnControllerが通常敵の出現を担うため、進行条件と敵配置の処理を別々に追えます。これは現在の実装を振り返ったときの利点であり、当時の設計意図を示すものではありません。

5. 課題と今後の改善案

表示Wave番号より1大きい番号を生成器へ渡しているため、番号と敵比重・ボス周期の対応を確認する必要があります。また、IntervalWaveData.readyTimeは生成されますが、進行側では使わずWave後に固定1秒待ちます。設定との対応を整理し、敵候補が空の場合などの境界条件も検査するのが改善候補です。

オトモスキルの装備から効果適用まで

1. 実装した機能

装備したスキルを出撃時に戦闘側へ渡し、手動入力またはスキルごとの自動設定に応じて発動します。共通のスキル情報と実行時の入口をSkillSOにまとめ、個別の効果を派生クラスに実装しています。

2. クラス構成

  • SkillSOはScriptableObjectの抽象クラスです。名前・カテゴリ・レアリティ・画像などの共通情報を持ち、GetDecCoolTime(int awakening)、GetEffectDiscription(int awakening)、Execute()を派生クラスに実装させます。表示用クールタイムは覚醒数を使って求めます。
  • OtomoSkillManagerは装備中のSkillSO参照をリストで管理します。出撃時にReplaceEquippedSkills()が装備枠からリストを作り直します。
  • OtomoSkillRunnerは戦闘開始時にそのリストを取得し、戦闘スロット表示、手動・自動発動、クールタイムを処理します。

3. 処理の流れ

  1. 装備画面で選んだスキルを装備枠に設定します。出撃時にHomeSceneController.GoGameScene()がOtomoSkillManager.ReplaceEquippedSkills()を呼び、装備枠の参照を管理リストへ入れます。

  2. OtomoSkillRunner.Start()がそのリストを受け取り、対応する戦闘スロットへ表示します。RunnerとManagerは同じリスト、各画面は同じSkillSOアセット参照を使います。

  3. Z / X / C入力と自動発動のどちらもSkillExecute()へ進み、クールタイム終了状態を確認してからSkillSO.Execute()を呼びます。続いてUpdateCoolTime()が終了状態と残り時間の表示を更新します。

4. 設計上の工夫と利点

共通情報と抽象メソッドをSkillSOに置くことで、Runnerは個々のスキル型ごとに分岐せず共通のExecute()を呼べます。新しい効果は派生クラスで実装でき、装備リストの管理はOtomoSkillManager、発動とクールタイムはOtomoSkillRunnerが担います。これは現在の構造を振り返った評価であり、当時の意図を断定するものではありません。

5. 課題と今後の改善案

IsEndCoolTimeはSkillSOインスタンス上の実行時状態で、アセットにシリアライズされる設定値ではありません。Runnerが同じアセット参照の値を更新するため、その参照を使う箇所では状態も共有されます。さらに、自動発動条件が続く間はUpdate()から毎フレーム待機コルーチンを開始するため、発動待ちが重なる可能性があります。手動入力は固定の3キーで、SkillExecute(index)にリスト範囲の確認もありません。スキル数・枠数を変更する前に、状態を装備ごとに持たせる方法、待機処理の重複防止、入力と枠数の境界チェックを整理するのが改善候補です。
