Bomb Crash

凍結爆弾でカウントダウン式の敵を迎撃し、スクラップを集めながらWaveの攻略に挑む2Dアクションゲームです。

ゲーム概要 制作体制・技術の見どころ ゲーム進行 設定画面・実装範囲 Wave生成・オトモスキルの実装 ソースコード・関連資料

ゲーム概要

Bomb Crashは、凍結爆弾の着弾位置を調整しながら、爆発までのカウントダウンがある敵を迎撃してWaveを攻略する2Dアクションゲームです。

  • 敵はHPと爆発までのカウントダウンを持ち、時間内に倒せないと爆発してゲームオーバーになります。
  • 爆弾の所持数には上限があり、時間経過で補充されます。
  • 敵を倒すとスクラップを獲得します。到達Waveなどに応じた知見ポイント（IP）はリザルトに反映されます。
  • 敵の出現が終わり、フィールド上の敵をすべて倒すと次のWaveへ進みます。Wave数に応じて敵が強くなり、一定間隔でスタンピードやボスが登場します。
  • オトモスキルはZ / X / Cで発動でき、自動発動に設定することもできます。必殺技は使用可能なときにVキーで発動します。

操作

  • 左右移動: ← / →、爆弾の着弾位置調整: ↑ / ↓、爆弾を投げる: Space
  • 装備スキル: Z / X / C、必殺技（使用可能時）: V
  • ホーム画面などのUI操作: マウスクリック、ゲームオーバー演出後にホームへ戻る: Space

ゲーム進行

出撃して敵を迎撃し、Waveを攻略します。プレイ終了時はリザルトを確認し、次の出撃に備えて装備を整えます。

プレイの基本ループと終了条件

  1. 出撃する

    ホーム画面から戦闘を開始します。

  2. 敵を迎撃する

    凍結爆弾の着弾位置を調整し、出現する敵を攻撃します。

  3. Waveを攻略する

    敵の出現が終わり、フィールド上の敵をすべて倒すと次のWaveへ進みます。

  4. プレイを終える

    敵のカウントダウンが尽きて爆発するとゲームオーバーです。リザルトで到達Waveや獲得資源を確認します。

オトモスキルの装備と発動

  1. オトモにスキルを装備する

    装備スロットに使用するスキルを設定します。

  2. 発動方法を選ぶ

    スキルごとに手動発動または自動発動を設定します。

  3. 戦闘中に発動する

    手動の場合はZ / X / Cで発動します。自動の場合は設定とクールタイムに応じて発動します。

装備を整える

  1. スクラップを集める

    敵を倒して装備の購入・強化に使う資源を獲得します。

  2. 装備を購入・強化する

    集めたスクラップを使って装備を整えます。

  3. 次の出撃に備える

    整えた装備で、さらに先のWaveへ挑戦します。

オトモを編成する

  1. オトモを解放する

    到達Waveの条件を満たしてオトモを解放します。

  2. オトモにスキルを設定する

    解放したオトモに、戦闘で使用するスキルを装備します。

  3. 戦闘で支援を受ける

    装備したスキルが、設定した発動方法に応じて戦闘中に発動します。

実装の見どころ：Wave生成とオトモスキル

Wave設定から敵の出現まで

実装している仕組み

EndlessWaveRuleに通常Wave・スタンピードの条件と、敵ごとの登場開始Wave・ピークWave・最大比重を設定します。Wave番号を受け取ったWaveGenerator.GenerateWaveは、出現時間や間隔、敵候補の比重を計算し、1回分のIntervalWaveDataを作ります。敵の出現数を先に固定するのではなく、Wave時間と出現間隔に沿って敵を生成します。

クラスとデータの受け渡し

  • EndlessWaveRule / EnemyScalingPattern: Wave条件と敵パターンを保持します。
  • WaveGenerator: 条件から時間・間隔・スタンピード状態・重み付き敵候補を計算します。
  • IntervalWaveData: 生成したWave条件とEnemySO・重みの候補配列を運びます。
  • WaveManager: Wave番号、ボス判定、タイマー、UI、Wave終了を管理します。
  • EnemySpawnController: 候補を重みで選び、位置を決めて敵を生成し、HPを設定します。

設定から次のWaveまで

  1. WaveManagerがWaveを開始し、WaveGenerator.GenerateWaveにWave番号とEndlessWaveRuleを渡します。

  2. WaveGeneratorが敵の開始Waveを確認し、ピークWaveまでの比重を線形補間してIntervalWaveDataを返します。

  3. 通常WaveではWaveManagerからEnemySpawnControllerへデータを渡します。敵の出現終了後、フィールド上の敵がいなくなると次のWaveへ進みます。

変更できる範囲と改善候補

既存の敵パターンなら、敵データとルールアセットの組み合わせで登場時期や比重を調整できます。別のWave種別を増やす場合は、生成データやWaveManagerの分岐も変更対象になります。現在のコードでは表示Wave番号より1大きい番号を生成器へ渡し、IntervalWaveData.readyTimeは進行側で使わず固定1秒待っています。番号と待機時間の扱い、敵候補が空の場合の検査は見直し候補です。

オトモスキルの装備から効果適用まで

実装している仕組み

装備したスキルを出撃時に戦闘側へ渡し、キー入力または個別設定に応じた自動発動で実行します。スキルごとの効果はSkillSOを継承するクラスに実装されています。

クラス構成

  • SkillDatabaseとSkillInventoryManager: スキルSOの一覧からインベントリ表示を作り、stockを更新します。
  • OtomoSkillStatusSlotController / OtomoSkillStatusSlot: 装備枠への設定と、手動・自動の選択を扱います。
  • OtomoSkillManager: 出撃時に装備枠からスキル参照を集め、装備中リストを更新します。
  • OtomoSkillRunner: 戦闘時スロットへの反映、発動条件、スキル実行、クールタイムを処理します。
  • SkillSOと派生クラス: 共通のスキル情報・実行口と、個別の効果処理を定義します。

装備から効果実行まで

  1. 装備画面で選んだスキルを、OtomoSkillStatusSlotControllerが装備枠へ設定します。

  2. 出撃時にHomeSceneControllerがOtomoSkillManager.ReplaceEquippedSkillsを呼び、装備枠のSkillSO参照を一覧に移します。

  3. OtomoSkillRunnerが一覧を戦闘UIへ反映します。Z / X / Cの入力、または敵がいるときの自動発動設定を確認します。

  4. 発動可能ならSkillSO.Executeを呼び、クールタイムと戦闘中UIを更新します。派生クラスがゲーム側の処理へ効果を適用します。

拡張範囲と改善候補

新しい効果はSkillSOの派生クラスとスキルデータを追加する形で作れます。一方、現在のSkillSOは設定情報だけでなく自動・CT状態も持ち、Runnerは発動・クールタイム・UI更新をまとめて扱います。装備単位の状態管理、キーと枠数の境界確認、自動発動コルーチンの重複防止は、今後整理できる点です。
