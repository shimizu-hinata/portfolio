Bomb Crash

凍結爆弾でカウントダウン式の敵を迎撃し、スクラップを集めながらWaveの攻略に挑む2Dアクションゲームです。

ゲーム概要 制作体制・技術の見どころ ゲーム進行 設定画面・実装範囲 Wave生成の実装 ソースコード・関連資料

ゲーム概要

Bomb Crashは、着弾位置を調整して凍結爆弾を投げ、爆発までのカウントダウンがある敵を迎撃する2Dアクションゲームです。敵を倒してWaveを進め、スクラップで装備を購入・強化します。

  • 敵はHPと爆発までのカウントダウンを持ち、時間内に倒せないと爆発してゲームオーバーになります。
  • 爆弾には所持数の上限があり、時間経過で補充されます。敵を倒すとスクラップを獲得し、到達Waveなどに応じた知見ポイント（IP）がリザルトに反映されます。
  • 敵の出現が終わり、フィールド上の敵を全て倒すと次のWaveへ進みます。Wave数に応じて敵が強くなり、一定間隔でスタンピードやボスが登場します。
  • オトモスキルはZ / X / Cで発動し、自動発動する設定もあります。必殺技は使用可能なときにVキーで発動します。

操作

  • 左右移動: ← / →、爆弾の着弾位置調整: ↑ / ↓、爆弾を投げる: Space
  • 装備スキル: Z / X / C、必殺技（使用可能時）: V
  • ホーム画面などのUI操作: マウスクリック、ゲームオーバー演出後にホームへ戻る: Space

Wave生成

WaveManagerがWaveGeneratorを呼び出して各Waveの出現データを作り、EnemySpawnControllerの敵選択・配置につなげます。

ゲームの基本ループ

出撃して敵を迎撃し、Waveを進めながら装備を整えます。敵の爆発を防げなかった場合はゲームオーバーとなり、リザルトへ進みます。

出撃から次のWaveへ

  1. 出撃するホーム画面から戦闘を開始します。
  2. 敵を迎撃するWave設定に沿って出現する敵へ、着弾位置を調整した凍結爆弾を投げます。
  3. Waveを進める敵の出現が終わり、フィールド上の敵を倒すと次のWaveへ進みます。
  4. 装備を整える獲得したスクラップで装備を購入・強化し、次の出撃に備えます。

Wave設定から敵の出現へ

  1. Waveデータを生成するWaveManagerが現在のWaveに応じてWaveGeneratorを呼び出し、EndlessWaveRuleの設定から出現データを作ります。
  2. 敵を選んで配置するWaveGeneratorが敵の出現時間・間隔・候補の比重を計算し、EnemySpawnControllerがその比重を使って敵を選び、フィールドへ配置します。
  3. 敵を倒して次のWaveへ進むWaveManagerがWaveの進行を管理し、出現終了後にフィールド上の敵がいなくなると次のWaveへ移ります。

オトモスキルの装備・発動

  1. 装備を読み込む出撃時にOtomoSkillManagerが、装備スロットに設定されたスキルを読み込みます。
  2. 発動条件を確認するOtomoSkillRunnerがZ / X / Cの入力や自動発動の設定を確認します。
  3. スキルを実行するSkillSOの共通処理を呼び出し、クールタイム中の再発動を防ぎます。

装備を強化する

  1. スクラップを集める敵を倒して装備購入・強化に使う資源を獲得します。
  2. 装備を購入・強化するスクラップを使って装備を整えます。
  3. 次のWaveに備える強化した装備で、さらに先のWaveへ挑戦します。

オトモを戦闘に加える

  1. オトモを解放する到達Waveの条件を満たしてオトモを解放します。
  2. スキルを設定するオトモにスキルを装備し、手動または設定に応じた自動発動を選びます。
  3. スキルで支援する使用可能状態とクールタイムに応じて戦闘中に発動します。

実装の詳細：Wave生成とスキル発動

ここでは、Wave設定から敵の候補を作る処理と、オトモスキルの発動処理を詳しく紹介します。

Waveごとの出現データを作る

EndlessWaveRuleには通常Waveとスタンピードの時間・出現間隔、敵ごとの出現開始Wave・比重の最大値を設定します。WaveGeneratorは現在のWave番号から出現時間と間隔を決め、敵パターンごとの比重を計算してIntervalWaveDataを作ります。

敵パターンの開始Waveに達していない場合は候補に加えず、比重が0より大きい敵だけを出現候補にします。EnemySpawnControllerは候補の比重を使って敵を選び、WaveManagerがWave進行やボス・スタンピードを含む進行を管理します。
