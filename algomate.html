Algomate Colony

プレイヤーが神の視点からロボットたちに命令（プログラミング）を与え、コロニーの運営・発展を目指すシミュレーションゲームです。
現在のプロトタイプでは、Move・Gather・Depositを組み合わせ、資源の収集や格納など基本的な作業を自動化します。

ゲーム概要

このゲームでは、プレイヤーがキャラクターを直接操作することはありません。

ロボットの選択:マップ上のロボットを選択します。
コマンドの入力:選択したロボットに対して、画面に表示されるコマンドリストから命令を与えます。 最初は「移動（Move）」や「収集（Gather）」,「格納（Deposit）」といった基本的なコマンドから始まります。
ヒント: コマンドの概要は右上の設定ボタンから確認できます。
施設・補助入力の利用: ワールド上の施設をクリックして施設パネルを開き、拠点では必要素材を確認してレベルアップを行います。左下の補助入力では cmd:setting で設定、cmd:location でロケーション画面を開けます。

ゲームの目的は、これらのコマンドを組み合わせてロボットの行動を自動化し、効率的な生産ラインを構築することです。

現在プレイできる範囲

  • ロボットを選択し、Move・Gather・Depositで移動、資源収集、格納を指示。
  • 資源量や拠点レベルなどの基本情報を確認し、必要素材を使った拠点レベルアップを実行。
  • 左下の補助入力で cmd:setting / cmd:location を使用。Tabキーによる入力補完にも対応。

ゲームは開発中のプロトタイプです。READMEではMove・Gather・Depositによる基本的な運搬・格納をプレイ可能とし、チュートリアルにもwarehouseへの移動と格納が記載されています。一方、多様な施設や高度な構文、エネルギー管理などは今後の予定です。ここでは拡張された倉庫・生産施設の機能までは実装済みとして扱っていません。

ゲーム設計・処理フロー

ロボットに命令を入力し、資源を収集・格納して拠点を発展させるまでの流れです。

プレイの基本ループ

  1. ロボットを選択マップ上のロボットを選び、状態と命令対象を決める
  2. 命令を入力・実行Move・Gather・Depositでロボットの行動を指示する
  3. 資源を収集・格納ロボットが対象へ移動し、資源を拠点へ運ぶ
  4. 拠点レベルを上げる必要素材を集めて拠点をレベルアップする

コマンド実行の処理

  1. 定義を読み込むCommandLoaderがResources内のJSONからコマンド定義を取得
  2. 入力を検証CommandHandlerがコマンド名と引数を確認
  3. 順番に実行RobotCommandExecuteがMove・Gather・Depositの状態遷移を処理
  4. ロボットが行動移動・収集・格納を行い、Loop()による循環動作にも対応

チュートリアルの実際の手順

未完了またはリセット設定時に開始し、各サブタスクの完了を待って次へ進みます。

  1. ロボットを拠点へ移動ロボットを選択し、Cボタンで入力欄を開いてMove(location);を入力・確認して実行
  2. 資源を採集・格納Move(rock);・Gather(rock);の後、Move(warehouse);・Deposit(rock, 30);を実行
  3. 拠点レベルを上げるlocationパネルを開き、必要素材を集めてlevelUpボタンを実行
  4. タスクを完了各操作に対応したタスクを完了し、最後の「チュートリアルをクリアする」へ進む

ロボットの移動・障害物回避

  1. 目的地を設定Moveコマンドに応じて移動先を決める
  2. Waypointを生成現在地から目的地までを直線補間し、10個の経由点を作る
  3. 障害物を検出移動方向へRaycastを行い、通行を妨げる障害物を確認
  4. 回避して到達周囲のRaycast結果から進める方向を選び、目的地への経路を再生成

技術的な工夫・実装内容

  • WaypointとRaycastを用いた移動: PathfindingSystemが開始位置から目的地までを10分割して経由点を生成。RobotMovementが進行方向をRaycastで確認し、ObstacleAvoidanceHelperが候補方向の障害物状況から回避方向を選択。
  • コマンド定義のデータ化: Resources内のJSONからコマンド定義を読み込み、Move・Gather・Depositの引数検証に利用。
  • 検証と実行の分離: CommandHandlerによる入力検証、RobotCommandExecuteによる逐次実行、ロボット側の行動処理を役割ごとに構成。
  • 拠点レベルの解放情報: ScriptableObjectでレベルごとの必要素材と解放情報を管理。
  • 施設UI: FacilityManagerで施設パネルの表示切替やEscapeキーによる閉じる動作を管理。

現行仕様と今後の予定

実行できる主な命令はMove・Gather・Depositです。Loop()による循環動作と、cmd:setting / cmd:locationなどの補助入力があります。一方、if・for・whileなどの高度な構文や、より広い生産チェーン・エネルギー管理は今後の予定としてREADMEに記載されています。

ストーリー

荒廃した惑星に降り立ったあなたは、稼働限界が近いロボットたちを再起動し、失われた文明の技術を集めながら新たな拠点を築きます。
しかし、惑星の環境は過酷で、資源もエネルギーも不足気味です。限られた命令をどう組み合わせるかで、コロニーの未来は大きく変わります。
研究を進めるごとにロボットは賢くなり、単純作業だった運営はやがて巨大な自動化システムへと進化していきます。
