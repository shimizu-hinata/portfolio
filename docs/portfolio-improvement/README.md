# ポートフォリオ改善プロジェクト管理

## 最上位目標

ゲームプログラマーの採用担当者とエンジニアに向け、実在する作品・コード・画像・資料に基づいて、強み、作品の規模と状態、本人の担当範囲、実装上の工夫を短時間で正確に伝える。PC・スマートフォン双方の使いやすさ、アクセシビリティ、保守性も改善する。根拠のない主張や、本人が説明できない内容は掲載しない。

判断の優先順位は、事実の正確性、採用側の理解、実装根拠の追跡可能性、本人の説明可能性、情報設計と視覚品質、操作性・アクセシビリティ・性能、保守性、装飾の順とする。
